# Security Policy

## Supported versions

Security fixes are provided for the latest published version of Cine Prime. Users should upgrade to the latest release when fixes become available.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues, pull requests, or discussions.

If private vulnerability reporting is enabled for this repository, use GitHub's **Report a vulnerability** feature in the Security tab. Include the affected version, steps to reproduce, potential impact, and relevant logs or proof of concept. Avoid attaching personal media, databases, backups, API keys, tokens, or other private user data.

If the private reporting option is unavailable, do not publish technical details. Open a brief public issue asking the maintainers for a private reporting channel, without including the vulnerability details or proof of concept.

The maintainers will acknowledge reports as soon as reasonably possible and coordinate investigation, remediation, and disclosure with the reporter. Please allow reasonable time for investigation before making details public.

## Scope

Reports are especially relevant to local media-file handling, library/database integrity, backup and restore, metadata retrieval, and application update or packaging mechanisms.
