# Code of Conduct

## Our commitment

The Cine Prime community aims to be welcoming and constructive. We want participation from people with different backgrounds, experience levels, identities, and viewpoints.

## Expected behaviour

- Be respectful, considerate, and constructive.
- Discuss ideas and technical decisions, not personal attributes.
- Accept good-faith criticism and differing technical opinions.
- Give feedback that is specific, actionable, and focused on improving the project.
- Respect privacy. Do not publish another person's personal information without permission.

## Unacceptable behaviour

Harassment, discrimination, intimidation, personal attacks, deliberate disruption, doxxing, and publishing private information without consent are not acceptable.

## Scope and enforcement

This Code of Conduct applies in project spaces, including issues, pull requests, discussions, and other spaces where someone is representing the project.

Project maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behaviour is abusive or harmful. Decisions should be proportionate to the conduct and communicated with as much transparency as is appropriate while respecting privacy.

## Reporting

To report behaviour that violates this Code, use GitHub's private contact/reporting mechanisms for the repository owner. Do not post sensitive details publicly. The project currently has no separate moderation team or dedicated security contact; that should be established as the community grows.
